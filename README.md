# Utah Mountain Conditions
## End-to-End Data Engineering Project

!(Kings Peak)[Docs/Kings.Peak.jpg]

Welcome! This project showcases the movement of data from online sources to visual dashboards tracking mountain peak conditions for the 50 highest summits in Utah. Besides being able to explore more of my love for the mountains, I also designed this portfolio project to increase my skills and follow best practices in data engineering and analytics. Explore and enjoy!

## Data Architecture
The database follows the **medallion architecture** style. Data is first stored raw, transformed, and then loaded into tables ready for analysis and visualizations.
